  • 评分口径 = 旧曲 Top35 + 新曲 Top15，与官方一致；ra = floor(c × ds × min(100.5, 达成率) / 100)
  • 成绩由水鱼查分器提供，接口开放跨域，不需要密钥、不需要后端；令牌只发给水鱼接口并存在你本机浏览器
  • B50：填水鱼用户名直接拉；完整成绩：去水鱼官网登录 →「编辑个人资料」生成 Import-Token
  • 目标档位只认 97 / 98 / 99 / 99.5 / 100 / 100.5；水鱼系数表里的 98.9999 / 100.4999 是 0.0001% 宽的边界占位行，打不到且被整点档位严格压制，不作目标
  • 「总分增益」按 Top35 / Top15 竞争重算后的真实变化，增益 0 = 这张现在不进分
